# Аналіз проекту Avtoservis 2.1

Цей документ містить огляд структури та компонентів проекту, створений на основі автоматичного аналізу.

## Структура проекту

Проект є комплексним рішенням для автоматизації роботи станції технічного обслуговування (СТО). Він складається з наступних основних компонентів:

### 1. Мобільний додаток (`mobile`)
- **Технологія:** React Native (понижено до стабільної версії 0.76.6)
- **Платформи:** Android (iOS підтримується, але аналізувався Android)
- **Основні залежності:**
  - `react-navigation`: Навігація в додатку.
  - `axios`: HTTP клієнт для зв'язку з сервером.
  - `react-native-paper`: UI компоненти.
  - `react-native-chart-kit`: Графіки та діаграми.
  - `react-native-calendars`: Календар.
  - `@react-native-async-storage/async-storage`: Локальне сховище даних.
  - `react-native-screens`: Нативна оптимізація екранів (версія ~3.35.0).
  - `react-native-reanimated`: Анімації (версія ~3.16.1).
- **Скрипти складання:**
  - `mobile/android/build_release.bat`: Автоматизований скрипт для створення релізного APK файлу.

### 2. Серверна частина (`server`)
- **Технологія:** Node.js (Express).
- **Призначення:** API для мобільного додатку та веб-клієнта.

### 3. Веб-клієнт (`client`)
- **Технологія:** React.js.
- **Призначення:** Веб-інтерфейс для адміністраторів або клієнтів СТО.

### 4. Інші компоненти
- **`telegram-bot`**: Бот для сповіщень або взаємодії через Telegram.
- **`docs`**: Документація проекту.
- **`cloudflare`**: Скрипти для Cloudflare Workers.

## Інструкція зі створення релізного APK

У проекті налаштований скрипт для автоматичного створення релізної версії додатку для Android.

**Вимоги:**
- JDK 17
- Android SDK (API 35)

**Команда для запуску:**
```cmd
E:\Avtoservis 2.1\mobile\android\build_release.bat
```

**Результат:**
APK файл буде створений у папці `mobile/android/app/build/outputs/apk/release/app-release.apk`.

## Статус збірки (Build Status)

**Оновлення:** Версію React Native було успішно понижено з 0.79.6 (експериментальна) до 0.76.6 (стабільна) для вирішення конфліктів залежностей.
Також оновлено версії супутніх бібліотек (`react-native-screens`, `react-native-reanimated`, `react-native-safe-area-context`) та налаштування Gradle (оновлено до 8.8).

**Поточний стан:** Виконується збірка релізного APK.
