# Документація Avtoservis 2.0

Ця папка містить **актуальні** (підтримувані) документи про репозиторій.

## Основне
 
 - План покращення та синхронізації (Web vs Mobile): [IMPROVEMENT_PLAN.md](./IMPROVEMENT_PLAN.md)
 - План прибирання репозиторію: [CLEANUP_PLAN.md](./CLEANUP_PLAN.md)
- План міграції на Render і деплой проекту: [DEPLOY_RENDER_PLAN.md](./DEPLOY_RENDER_PLAN.md)

## Тимчасові обмеження

- OCR розпізнавання номера з фото тимчасово відключено у web flow додавання авто.
- Поточний сценарій: фото додається як звичайне зображення, номер/марка/модель вводяться вручну або через пошук по номеру.
- Повернення OCR заплановане після стабілізації базового функціоналу авто/клієнтів/записів.

## Про `.trae/documents/`

У `.trae/documents/` лежать згенеровані Trae-документи (PRD/архітектура/дизайн сторінок). Вони корисні як довідка, але можуть містити кілька версій і не збігатися з поточним кодом.

Рекомендація: підтримувати “канонічну” документацію в `docs/`, а все інше або архівувати, або явно маркувати як чернетки.
