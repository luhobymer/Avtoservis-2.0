# Форма Створення Запису

Описує поточну поведінку форми створення запису у web-клієнті.

## Де Реалізовано

- `client/src/pages/AppointmentDetails.jsx` (режим `isNewAppointment`)

## Поточна Логіка По Роботах

- Вибір робіт відбувається у 2 кроки:
1. Користувач обирає категорію робіт.
2. Користувач обирає одну або кілька робіт у межах категорії.

- Дії по роботах винесені у випадаюче меню `Дії з роботами`:
1. `Підтвердити вибір послуг`.
2. `Додати послугу`.

- Створення запису блокується, поки не підтверджено вибір послуг.

## Додавання Нової Роботи

- При дії `Додати послугу` відкривається діалог.
- Обов'язкове поле: `Назва`.
- Необов'язкові поля:
1. `Ціна`.
2. `Тривалість`.
3. `Категорія`.

- Категорії підтягуються з API:
1. `GET /api/service-categories`.
2. При збереженні у payload передається `category_id`.

## Рекомендації Для Подальшого Розвитку

- Додати inline-підтвердження обраної дії під меню (щоб користувач бачив, що саме виконано).
- Додати створення нової категорії прямо з діалогу додавання послуги.
